\section{Baseline System and Proposed Extensions}


{\small

This section describes the baseline implementation used as the starting point for this thesis and presents the modifications introduced in the proposed work. The baseline system is first analysed in terms of its main software components, data flow, and processing pipeline. This includes the original FastAPI-based interface, dataset input mechanism, worker-based processing structure, vision-language model interface, and scene graph generation module.

The proposed extensions are then described in detail. These include porting the framework to ROS 2 for improved integration with robotic systems, extending the scene graph generation process using SLAM-based spatial data and loop closure information, introducing probabilistic object representation to handle perception uncertainty, refining the vision-language model output into bounded and consistent scene graph information, and considering near-real-time operation during system design.

}
